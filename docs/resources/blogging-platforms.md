# ► Blogging Platforms

Platforms and tools used to create and publish blogs.

<hr class="blogr-intro-divider" aria-hidden="true" />



## Hosted Platforms

* **[WordPress.com](https://wordpress.com)** - Hosted version of WordPress, easy to get started.
* **[Ghost](https://ghost.org)** - Clean, modern publishing platform focused on writing.
* **[Substack](https://substack.com)** - Newsletter-style blogging with built-in audience tools.
* **[Medium](https://medium.com)** - Large publishing platform with built-in readership.
* **[Write.as](https://write.as)** - Minimal, privacy-focused writing platform.

## Self-Hosted Platforms

* **[WordPress.org](https://wordpress.org)** - Full control, plugins, themes, and flexibility.
* **[Ghost (Self-Hosted)](https://ghost.org/docs/install/)** - Fast, modern, and focused on content.
* **[Grav](https://getgrav.org)** - Flat-file CMS, no database required.
* **[Jekyll](https://jekyllrb.com)** - Static site generator used with GitHub Pages.
* **[Hugo](https://gohugo.io)** - Fast static site generator for blogs and sites.

## Modern & Developer-Friendly

* **[Astro](https://astro.build)** - Static-first framework for content-rich websites.
* **[Next.js](https://nextjs.org)** - React framework for building fast websites.
* **[Nuxt](https://nuxt.com)** - Vue-based framework for modern web apps.
* **[SvelteKit](https://svelte.dev)** - Lightweight framework for fast web apps.

## Minimal & Indie Platforms

* **[Bear Blog](https://bearblog.dev)** - Simple, no-nonsense blogging platform.
* **[Micro.blog](https://micro.blog)** - Indie blogging and micro-posting platform.
* **[Blot](https://blot.im)** - Turns a folder into a blog.
* **[Listed](https://listed.to)** - Blogging powered by Standard Notes.
