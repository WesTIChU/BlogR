# ► Contribute

BlogR Directory is maintained as a hand-curated collection. Contributions should include real websites, accurate descriptions, and working URLs.

When an approved blog is added to `data/blogs.json`, set its `addedDate` to
the actual UTC calendar date in `YYYY-MM-DD` format. Existing entries with an
unknown addition date use `null` and are not shown in the rolling Recently
Added list until their date is established.


Please check that a suggestion is not already listed and explain why it belongs in the directory.
