# ► Blogging Platforms

Platforms and tools used to create and publish blogs.

<hr class="blogr-intro-divider" aria-hidden="true" />

## Hosted Platforms

* **[Blogger](https://www.blogger.com/)** - Google's free blogging platform, around since 1999.
* **[DEV Community](https://dev.to/)** - Community publishing platform for developers and technical writers.
* **[Ghost](https://ghost.org/)** - Modern publishing platform focused on writing, newsletters and memberships.
* **[Hashnode](https://hashnode.com/)** - Blogging platform for developers, with support for custom domains.
* **[Medium](https://medium.com/)** - Publishing platform with an established readership.
* **[Substack](https://substack.com/)** - Blogging and newsletters with subscriptions and audience tools.
* **[Tumblr](https://www.tumblr.com/)** - Social blogging platform for text, images, GIFs and multimedia.
* **[WordPress.com](https://wordpress.com/)** - Hosted WordPress blogging with themes and publishing tools.
* **[Write.as](https://write.as/)** - Minimal writing and blogging platform focused on simplicity.

## Self-Hosted Platforms


::: tip Free hosting for static websites
Building a lightweight blog with Hugo, Jekyll, Astro, VitePress or another static site generator? You may not need paid hosting at all.

Services such as [Cloudflare Pages](https://pages.cloudflare.com/), [GitHub Pages](https://pages.github.com/) and [Netlify](https://www.netlify.com/) offer free hosting tiers for static websites.

You can connect your GitHub repository and have your website automatically rebuilt and published whenever you push changes.

**Blogr.directory itself is built with VitePress and hosted on Cloudflare Pages**, showing that you don't need expensive hosting to run a directory or content-driven website.
:::

* **[ClassicPress](https://www.classicpress.net/)** - WordPress-derived CMS focused on traditional content publishing.
* **[Drupal](https://www.drupal.org/)** - Powerful open-source CMS for blogs and larger content websites.
* **[Ghost (Self-Hosted)](https://ghost.org/docs/install/)** - Self-hosted publishing software for blogs, newsletters and memberships.
* **[Grav](https://getgrav.org/)** - Flat-file CMS that doesn't require a database.
* **[Hugo](https://gohugo.io/)** - Fast static site generator widely used for personal blogs.
* **[Jekyll](https://jekyllrb.com/)** - Ruby-based static site generator with GitHub Pages support.
* **[Kirby](https://getkirby.com/)** - Flexible flat-file CMS with a customisable admin panel.
* **[ProcessWire](https://processwire.com/)** - Open-source CMS with flexible content management.
* **[Publii](https://getpublii.com/)** - Desktop application for creating and publishing static websites.
* **[Wagtail](https://wagtail.org/)** - Django-based open-source CMS for content-driven websites.
* **[WordPress.org](https://wordpress.org/)** - Self-hosted WordPress with full control over themes, plugins and content.
* **[WriteFreely](https://writefreely.org/)** - Lightweight, open-source blogging software with federation support.

## Modern & Developer-Friendly

* **[Astro](https://astro.build/)** - Content-focused web framework suited to blogs and static websites.
* **[Docusaurus](https://docusaurus.io/)** - React-based static site generator for documentation and content.
* **[Eleventy (11ty)](https://www.11ty.dev/)** - Flexible static site generator with support for several template languages.
* **[Gatsby](https://www.gatsbyjs.com/)** - React-based framework for content-driven websites.
* **[Hexo](https://hexo.io/)** - Node.js-powered static blogging framework.
* **[MkDocs](https://www.mkdocs.org/)** - Python-based static site generator for documentation.
* **[Next.js](https://nextjs.org/)** - React framework capable of building static and dynamic blogs.
* **[Nuxt](https://nuxt.com/)** - Vue framework for building content-driven websites.
* **[Pelican](https://getpelican.com/)** - Python-powered static site generator for blogs.
* **[SvelteKit](https://svelte.dev/docs/kit/introduction)** - Svelte framework for fast, modern websites.
* **[VitePress](https://vitepress.dev/)** - Vite-powered static site generator used for documentation and content websites. Blogr.directory itself is built with VitePress.
* **[Zola](https://www.getzola.org/)** - Fast static site generator written in Rust.

## Minimal & Indie Platforms

* **[Bear Blog](https://bearblog.dev/)** - Lightweight blogging platform focused on writing rather than design.
* **[Blot](https://blot.im/)** - Turns files in a folder into a published blog.
* **[Listed](https://listed.to/)** - Blogging platform powered by Standard Notes.
* **[Mataroa](https://mataroa.blog/)** - Minimal blogging service with an emphasis on writing.
* **[Micro.blog](https://micro.blog/)** - Indie blogging and microblogging with support for the open web.
* **[Neocities](https://neocities.org/)** - Hosting for independent personal websites and hand-built blogs.
* **[Nekoweb](https://nekoweb.org/)** - Indie web hosting for personal websites and creative projects.
* **[Pika](https://pika.page/)** - Simple blogging platform for personal publishing.
* **[TiddlyWiki](https://tiddlywiki.com/)** - Personal wiki and publishing software that can run from a single HTML file.
