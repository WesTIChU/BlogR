# ► Self-Hosting Apps

Applications and services you can run on your own server, from community forums and website analytics to monitoring, newsletters and automation.

<hr class="blogr-intro-divider" aria-hidden="true" />

## Communities & Forums

* **[Discourse](https://www.discourse.org/)** - Open-source discussion platform with categories, moderation and community tools.
* **[Flarum](https://flarum.org/)** - Lightweight forum software with a modern interface and extensions.
* **[Lemmy](https://join-lemmy.org/)** - Federated link-sharing and discussion platform.
* **[MyBB](https://mybb.com/)** - Free, open-source forum software with themes and plugins.
* **[NodeBB](https://nodebb.org/)** - Node.js forum platform with real-time discussions.
* **[phpBB](https://www.phpbb.com/)** - Long-running open-source forum software built with PHP.
* **[Simple Machines Forum](https://www.simplemachines.org/)** - Free PHP forum software, commonly known as SMF.
* **[vBulletin](https://www.vbulletin.com/)** - Commercial forum and community software.
* **[XenForo](https://xenforo.com/)** - Commercial self-hosted forum software used by established online communities.

## Comments & Interaction

* **[Commento](https://commento.io/)** - Lightweight commenting system with a focus on privacy.
* **[Cusdis](https://cusdis.com/)** - Open-source, lightweight commenting system.
* **[Giscus](https://giscus.app/)** - Comment system powered by GitHub Discussions.
* **[Isso](https://isso-comments.de/)** - Lightweight, self-hosted commenting system.
* **[Remark42](https://remark42.com/)** - Privacy-conscious commenting engine with multiple authentication options.
* **[Staticman](https://staticman.net/)** - Adds user-generated comments and content to static websites through Git repositories.
* **[Utterances](https://utteranc.es/)** - GitHub Issues-powered commenting system.

## Analytics (Privacy-Friendly)

* **[Ackee](https://ackee.electerious.com/)** - Self-hosted analytics focused on privacy.
* **[GoatCounter](https://www.goatcounter.com/)** - Lightweight website analytics with a self-hosting option.
* **[Matomo](https://matomo.org/)** - Full-featured analytics platform with visitor and campaign reporting.
* **[Offen](https://www.offen.dev/)** - Privacy-friendly analytics that gives visitors control over their data.
* **[Plausible](https://plausible.io/)** - Lightweight, privacy-focused analytics with a self-hosted edition.
* **[Umami](https://umami.is/)** - Open-source website analytics with a simple dashboard.

## Monitoring & Uptime

* **[Beszel](https://beszel.dev/)** - Lightweight server monitoring with resource usage and alerts.
* **[Cachet](https://cachethq.io/)** - Open-source status page software for reporting incidents and outages.
* **[Gatus](https://gatus.io/)** - Automated service health monitoring with configurable alerts.
* **[Glances](https://nicolargo.github.io/glances/)** - Cross-platform system monitoring dashboard.
* **[Grafana](https://grafana.com/)** - Dashboards and visualisation for metrics, logs and monitoring data.
* **[Healthchecks](https://healthchecks.io/)** - Monitoring for cron jobs and scheduled tasks.
* **[Netdata](https://www.netdata.cloud/)** - Real-time infrastructure and system monitoring.
* **[ntfy](https://ntfy.sh/)** - Self-hostable push notification service for alerts and scripts.
* **[Prometheus](https://prometheus.io/)** - Open-source metrics collection and alerting system.
* **[Uptime Kuma](https://github.com/louislam/uptime-kuma)** - Self-hosted uptime monitoring with notifications and status pages.

## Newsletters & Email

* **[Keila](https://www.keila.io/)** - Open-source email newsletter and campaign management software.
* **[Listmonk](https://listmonk.app/)** - Self-hosted newsletter and mailing list manager.
* **[Mailcow](https://mailcow.email/)** - Docker-based email server suite with administration tools.
* **[Mailtrain](https://github.com/Mailtrain-org/mailtrain)** - Self-hosted newsletter and email campaign platform.
* **[Mautic](https://www.mautic.org/)** - Open-source marketing automation and email campaign software.
* **[Postal](https://docs.postalserver.io/)** - Open-source mail delivery platform for applications and services.
* **[Roundcube](https://roundcube.net/)** - Browser-based webmail client for existing mail servers.

## Automation & Integrations

* **[Activepieces](https://www.activepieces.com/)** - Open-source workflow automation platform.
* **[Apache Airflow](https://airflow.apache.org/)** - Workflow orchestration for scheduled and data-processing tasks.
* **[Automatisch](https://automatisch.io/)** - Open-source automation platform for connecting apps and services.
* **[Huginn](https://github.com/huginn/huginn)** - Self-hosted agents that monitor websites and automate actions.
* **[Kestra](https://kestra.io/)** - Open-source workflow orchestration and automation platform.
* **[Node-RED](https://nodered.org/)** - Visual programming tool for connecting devices, APIs and services.
* **[n8n](https://n8n.io/)** - Workflow automation with integrations and visual editing.
* **[Windmill](https://www.windmill.dev/)** - Developer-focused automation platform for scripts, workflows and internal tools.

## File Sharing & Cloud Storage

* **[File Browser](https://filebrowser.org/)** - Web-based file manager for files stored on your server.
* **[FileGator](https://filegator.io/)** - Lightweight web-based file manager and sharing application.
* **[Nextcloud](https://nextcloud.com/)** - Self-hosted cloud storage, file sharing and collaboration platform.
* **[OwnCloud](https://owncloud.com/)** - File synchronisation and sharing platform.
* **[Pingvin Share](https://github.com/stonith404/pingvin-share)** - Self-hosted file-sharing application with expiring links.
* **[Seafile](https://www.seafile.com/)** - File synchronisation and sharing platform.
* **[Syncthing](https://syncthing.net/)** - Peer-to-peer file synchronisation between devices.

## Backups & Data Protection

* **[BorgBackup](https://www.borgbackup.org/)** - Deduplicating backup tool with encryption and compression.
* **[Duplicati](https://duplicati.com/)** - Encrypted backup software with a web interface and cloud storage support.
* **[Kopia](https://kopia.io/)** - Fast, encrypted backup tool with snapshot management.
* **[Restic](https://restic.net/)** - Open-source backup utility supporting multiple storage backends.
* **[UrBackup](https://www.urbackup.org/)** - Client/server backup system for files and disk images.

## Passwords & Security

* **[Authelia](https://www.authelia.com/)** - Authentication and authorisation service for protecting web applications.
* **[Authentik](https://goauthentik.io/)** - Identity provider supporting single sign-on and access management.
* **[CrowdSec](https://www.crowdsec.net/)** - Collaborative security software for detecting and responding to malicious activity.
* **[Keycloak](https://www.keycloak.org/)** - Open-source identity and access management platform.
* **[Passbolt](https://www.passbolt.com/)** - Open-source password manager designed for teams.
* **[Vaultwarden](https://github.com/dani-garcia/vaultwarden)** - Lightweight, self-hosted server compatible with Bitwarden clients.
