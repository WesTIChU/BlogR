# ► About

BlogR Directory is a curated directory of human-written websites, independent blogs, and corners of the internet worth visiting.


Sites are found and checked by hand, then placed where they fit. The directory favours writing with a distinct human voice, useful niche sites, independent creators, and communities that still feel alive.

There is no attempt to build the largest list on the internet. The goal is to make discovery better: a place to stumble across a personal blog, a proper opinion, or a site someone clearly cares about.
