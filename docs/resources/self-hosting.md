# ► Self-Hosting

Tools and platforms for running your own servers, deploying applications, managing containers and accessing your services securely.

<hr class="blogr-intro-divider" aria-hidden="true" />

## Self-Hosting Platforms

* **[CapRover](https://caprover.com/)** - Self-hosted platform for deploying and managing applications.
* **[CasaOS](https://casaos.io/)** - Home server dashboard with an app-store style interface.
* **[Coolify](https://coolify.io/)** - Self-hosted deployment platform for applications, databases and websites.
* **[Dokku](https://dokku.com/)** - Lightweight platform for deploying applications to your own server.
* **[FreedomBox](https://freedombox.org/)** - Debian-based personal server platform with a web interface.
* **[OpenMediaVault](https://www.openmediavault.org/)** - NAS operating system for managing storage and network services.
* **[Proxmox VE](https://www.proxmox.com/en/products/proxmox-virtual-environment/overview)** - Virtualisation platform for running virtual machines and containers.
* **[Runtipi](https://runtipi.io/)** - Home server application management with a web interface.
* **[TrueNAS](https://www.truenas.com/)** - Network-attached storage platform for managing files and storage.
* **[Umbrel](https://umbrel.com/)** - Personal server platform with an app-store style experience.
* **[Unraid](https://unraid.net/)** - Home server operating system for storage, Docker containers and virtual machines.
* **[YunoHost](https://yunohost.org/)** - Debian-based platform for hosting web applications and services.

## Containers & Infrastructure

* **[containerd](https://containerd.io/)** - Container runtime used by container platforms and orchestration tools.
* **[Docker](https://www.docker.com/)** - Container platform for packaging and running applications.
* **[Docker Compose](https://docs.docker.com/compose/)** - Define and manage multi-container applications using YAML files.
* **[Docker Swarm](https://docs.docker.com/engine/swarm/)** - Native Docker clustering and container orchestration.
* **[Dockge](https://github.com/louislam/dockge)** - Web interface for managing Docker Compose stacks.
* **[K3s](https://k3s.io/)** - Lightweight Kubernetes distribution suited to smaller servers.
* **[Kubernetes](https://kubernetes.io/)** - Container orchestration platform for managing workloads across servers.
* **[LinuxServer.io](https://www.linuxserver.io/)** - Maintained container images for popular self-hosted applications.
* **[LXC](https://linuxcontainers.org/lxc/)** - Linux system containers for lightweight virtualised environments.
* **[Podman](https://podman.io/)** - Daemonless container engine for running OCI containers.
* **[Portainer](https://www.portainer.io/)** - Web-based container management platform.
* **[Watchtower](https://github.com/containrrr/watchtower)** - Automates updates of running container images; review compatibility and maintenance before use.

## Networking & Remote Access

* **[Cloudflare](https://www.cloudflare.com/)** - DNS, CDN, security and connectivity services.
* **[Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/)** - Publish services through outbound connections without opening inbound ports.
* **[Caddy](https://caddyserver.com/)** - Web server and reverse proxy with automatic HTTPS.
* **[Headscale](https://headscale.net/)** - Open-source, self-hosted control server compatible with Tailscale clients.
* **[NetBird](https://netbird.io/)** - WireGuard-based private networking with self-hosting options.
* **[Nginx](https://nginx.org/)** - Web server, reverse proxy and load balancer.
* **[Nginx Proxy Manager](https://nginxproxymanager.com/)** - Web interface for managing reverse proxies and HTTPS certificates.
* **[OpenVPN](https://openvpn.net/)** - VPN technology for encrypted remote network access.
* **[Tailscale](https://tailscale.com/)** - Mesh VPN for connecting devices and services securely.
* **[Traefik](https://traefik.io/)** - Reverse proxy with automatic service discovery and routing.
* **[WireGuard](https://www.wireguard.com/)** - Lightweight VPN protocol and software.
* **[Zoraxy](https://zoraxy.aroz.org/)** - Reverse proxy with a web-based management interface.

## DNS & Certificates

* **[AdGuard Home](https://adguard.com/en/adguard-home/overview.html)** - Network-wide DNS filtering and ad blocking.
* **[acme.sh](https://github.com/acmesh-official/acme.sh)** - Shell-based ACME client for obtaining and renewing TLS certificates.
* **[Certbot](https://certbot.eff.org/)** - ACME client for managing Let's Encrypt certificates.
* **[CoreDNS](https://coredns.io/)** - Flexible DNS server commonly used in container environments.
* **[Duck DNS](https://www.duckdns.org/)** - Free dynamic DNS service for changing public IP addresses.
* **[Let's Encrypt](https://letsencrypt.org/)** - Free certificate authority for HTTPS certificates.
* **[Pi-hole](https://pi-hole.net/)** - DNS-based network-wide ad and tracker blocking.
* **[Technitium DNS Server](https://technitium.com/dns/)** - DNS server with filtering, caching and management features.

## Server Management & Administration

* **[Ansible](https://www.ansible.com/)** - Automate server configuration, deployment and maintenance.
* **[Cockpit](https://cockpit-project.org/)** - Web-based Linux server administration interface.
* **[Fail2ban](https://github.com/fail2ban/fail2ban)** - Helps protect services by blocking repeated suspicious login attempts.
* **[Netdata](https://www.netdata.cloud/)** - Real-time monitoring for servers and infrastructure.
* **[OpenSSH](https://www.openssh.com/)** - Secure remote shell access and file transfer.
* **[Rclone](https://rclone.org/)** - Command-line tool for transferring and synchronising files across storage providers.
* **[Restic](https://restic.net/)** - Encrypted backup software for files and server data.
* **[Terraform](https://www.terraform.io/)** - Infrastructure-as-code tool for provisioning and managing resources.
* **[UFW](https://launchpad.net/ufw)** - Simplified firewall management for Linux.
* **[Webmin](https://webmin.com/)** - Browser-based administration interface for Unix-like systems.
