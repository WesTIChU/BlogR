# ► Self-Hosting

Tools and guidance for hosting your own website.

<hr class="blogr-intro-divider" aria-hidden="true" />



## Self-Hosting Platforms

* **[Coolify](https://coolify.io)** - Self-hosted alternative to Vercel and Heroku with a clean UI.
* **[CapRover](https://caprover.com)** - Self-hosted alternative to Heroku with simple app deployments.
* **[Dokku](https://dokku.com)** - Lightweight, self-hosted Heroku-style platform.
* **[Umbrel](https://umbrel.com)** - Personal server platform with an app-store style experience.
* **[CasaOS](https://casaos.io)** - Beginner-friendly home server dashboard.

## Containers & Infrastructure

* **[Docker](https://www.docker.com)** - Runs apps in containers.
* **[Portainer](https://www.portainer.io)** - UI for managing Docker containers.
* **[Kubernetes](https://kubernetes.io)** - Container orchestration at scale.
* **[LinuxServer.io](https://www.linuxserver.io)** - Prebuilt Docker containers for common apps.

## Networking & Access

* **[Tailscale](https://tailscale.com)** - Secure remote access from anywhere.
* **[Nginx Proxy Manager](https://nginxproxymanager.com)** - Easy reverse proxy with SSL.
* **[Traefik](https://traefik.io)** - Advanced reverse proxy for dynamic setups.
* **[Cloudflare](https://www.cloudflare.com)** - DNS, security, and CDN in front of your server.
